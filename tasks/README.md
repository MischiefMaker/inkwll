# Task board

Each piece of work has its own file in this folder, named `NNNN-short-name.md`. Copy `TEMPLATE.md` to start a new one, and add a row here.

How a task moves:

**Open** (not started) → **Doing** (Claude is on it) or **Handed off** (sent to another AI) → **Review** (an answer is in `inbox/`, waiting for Claude) → **Done**

Done tasks stay in this folder as a record.
